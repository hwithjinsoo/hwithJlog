정규표현식은 **특정 문자열을 가리키는 게 아니라**, "이 자리에는 어떤 문자가 와야 한다"는 **패턴**을 정의하는 도구다.

예를 들어 `\w{5,7}` 은 `hello` 도 맞고 `abc123` 도 맞고 `foo_bar` 도 맞다. 하나의 문자열을 지정하는 게 아니라 조건을 만족하는 문자열이면 전부 매칭된다.

---

## 자주 쓰는 메타문자

| 패턴 | 의미 | 예시 매칭 |
|------|------|-----------|
| `\w` | 알파벳, 숫자, 언더스코어 (`[a-zA-Z0-9_]`) | `a`, `Z`, `3`, `_` |
| `\d` | 숫자 (`[0-9]`) | `0`, `5`, `9` |
| `\s` | 공백 문자 (스페이스, 탭, 개행) | ` `, `\t`, `\n` |
| `.` | 줄바꿈 제외 모든 문자 | `a`, `!`, `3` |
| `\W` | `\w` 의 반대 | `!`, `@`, ` ` |
| `\D` | `\d` 의 반대 | `a`, `!`, ` ` |

---

## 수량자 (Quantifier)

| 패턴 | 의미 |
|------|------|
| `{n}` | 정확히 n번 |
| `{n,m}` | n번 이상 m번 이하 |
| `+` | 1번 이상 |
| `*` | 0번 이상 |
| `?` | 0번 또는 1번 |

```python
\w{5,7}   # 단어 문자 5~7글자
\d+       # 숫자 1개 이상
[a-z]*    # 소문자 0개 이상
```

---

## 문자 클래스 `[]`

대괄호 안에 들어갈 수 있는 문자를 직접 지정한다.

```python
[a-z]       # 소문자 알파벳 하나
[A-Z]       # 대문자 알파벳 하나
[0-9]       # 숫자 하나 (\d 와 동일)
[a-zA-Z0-9] # 알파벳 + 숫자
[^abc]      # a, b, c 를 제외한 문자
```

---

## 이스케이프 `\.`

`.` 는 메타문자라서 "모든 문자"를 의미한다.  
실제 점(`.`)을 매칭하려면 `\.` 처럼 이스케이프해야 한다.

```python
\.   # 실제 점 문자
\d   # 숫자 (백슬래시로 특수 의미 부여)
```

---

## 예시 패턴 분석

```python
'dr\w{5,7}e\d+am@[a-z]{3,7}\.\w+'
```

| 부분 | 의미 |
|------|------|
| `dr` | 고정 문자 "dr" |
| `\w{5,7}` | 단어 문자 5~7글자 |
| `e` | 고정 문자 "e" |
| `\d+` | 숫자 1개 이상 |
| `am@` | 고정 문자 "am@" |
| `[a-z]{3,7}` | 소문자 3~7글자 |
| `\.` | 실제 점 문자 |
| `\w+` | 단어 문자 1개 이상 |

매칭 예시:
```
dreeeame1am@abc.com
drfoobare2am@hello.net
```

---

## Python에서 사용하기

```python
import re

pattern = r'dr\w{5,7}e\d+am@[a-z]{3,7}\.\w+'
text = 'dreeeame1am@abc.com'

# 매칭 여부 확인
if re.match(pattern, text):
    print("매칭됨")

# 문자열에서 찾기
result = re.search(pattern, text)

# 전체 찾기
results = re.findall(pattern, text)
```

---

## 핵심 요약

- 정규식은 **패턴**이다. 특정 문자열 하나가 아니라 조건을 만족하는 모든 문자열에 매칭된다.
- `\w`, `\d`, `\s` 같은 메타문자로 문자 종류를 지정한다.
- `{n,m}`, `+`, `*` 같은 수량자로 반복 횟수를 지정한다.
- `[]` 로 허용할 문자 범위를 직접 지정할 수 있다.
- 실제 특수문자(`.`, `*` 등)를 매칭하려면 `\` 로 이스케이프한다.
