### Challenge Analysis

이번 문제는 tomcat의 취약점을 이용해서 flag를 가져오는 문제예요.  

페이로드 순서는 다음과 같아요.
1. "tomcat"이라는 계정을 알아내요.  
2. /manager 페이지에 접근해요  
3. 웹 쉘을 서버에 업로드해 flag를 탈취해요.

______________________________

## Payload
image.jsp의 파라미터로 이미지를 호출하고 있는 걸 알 수 있어요.

______________________________

다음으로 문제에서 주어진 코드를 보고서 file 이름을 따로 검증하지 않고 아무거나 다 받는다는걸 인지하고서 넘어가볼께요.  

```java
<%@ page trimDirectiveWhitespaces="true" %>
<%
String filepath = getServletContext().getRealPath("resources") + "/";
String _file = request.getParameter("file");

response.setContentType("image/jpeg");
try{
    java.io.FileInputStream fileInputStream = new java.io.FileInputStream(filepath + _file);
    int i;   
    while ((i = fileInputStream.read()) != -1) {  
        out.write(i);
    }   
    fileInputStream.close();
}catch(Exception e){
    response.sendError(404, "Not Found !" );
}
%>
```

우리의 첫번째 목표는 "tomcat" 계정 정보를 알아내 /manager 페이지에 접근하는것이기에  
/tomcat-user-xml 경로로 접근해야해요. 그럴려면 위 파일 경로 취약점을 이용해 접근해볼께요.

절대경로로는 접근이 불가능하기에 상대경로로 입력해보면 접근이 가능해요.  
아래 사진을 보면 tomcat의 pw가 나와있어요. 이걸로 /manager 페이지에 접근해볼께요.

드디어 해당 서버를 마음대로 할 수 있는 /manager 페이지에 접근했어요.
사진을 보면 "WAR file to deploy" 목록이 있는데 여기는 **.war 형식의 파일을 업로드하면 서버가 자동으로 .jsp 형식으로 변환해서 읽는 곳이에요.**   
우리는 flag를 얻어야하기 때문에 **서버에 웹쉘을 심어서 쉘을 탈취해야해요.**  
이에 인터넷에서 웹쉘 코드를 가져와 .war 형식으로 서버에 업로드 하면 돼요.
