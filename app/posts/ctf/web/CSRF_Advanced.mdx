### Challenge Analysis
이번 문제는 csrf를 통해 서버 내부에 작동중인 셀레니움을 통해 서버를 속여  
여러 방화벽 장치를 우회해 admin 계정의 pw를 변경해 flag를 얻는 문제이다

페이로드 순서는 다음과 같다.  
1. admin의 pw를 변경하기 위해 해당 권한을 애초에 가지고 있는 셀레니움 봇을 이용한다.
2. xss 필터, 세션 검증, token 검증을 우회한다.
3. token 검증 우회를 위해 admin 권한의 token을 생성한다.  
4. 위 데이터로 페이로드를 작성해 익스플로잇 한다.

### Payload

페이로드 순서를 봐보자.
1. **admin** 세션을 가지고서 "/change_password" 페이지에 접근해야한다.  
2. admin + 127.0.0.1 값을 해싱한 token을 제출해야한다

먼저 admin 세션을 가지고 페이지에 붙으려면 셀레니움 봇을 이용하면 된다.  
"/flag" 페이지에서 이미지 태그로 /change_password로 붙으면 된다. 셀레니움 봇은 이미 admin 권한을 가지고 있기에  
위와 같이 페이지에 붙으면 서버는 admin이라고 볼 수 밖에 없다.

다음으로 우회할껀 admin + 127.0.0.1을 해싱한 값을 토큰으로 제출하는것이다.  
코드는 아래와 같다.  
```python
token = md5(("admin" + "127.0.0.1").encode()).hexdigest()

print(token)
```

```html

```
