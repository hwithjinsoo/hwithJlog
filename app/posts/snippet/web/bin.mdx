대회장 윈도우 PC에서 저 ZIP 파일 압축을 풀고, 해당 폴더 안에서 CMD 창을 열어 아래 명령어를 치면 실행돼.
python setup.py install

설치가 끝나면 binwalk 명령어를 쓰거나, 설치가 귀찮으면 폴더 안에서 아래처럼 파이썬으로 직접 실행하면 된다.
python -m binwalk -e 문제파일

빈walk는 파일 내부에 숨겨진 시그니처를 스캔하고 추출하는 툴이야. 텍스트로만 깔끔하게 요약해 줄게.
1. 기본 스캔
명령어 뒤에 파일 경로만 적으면 내부 구조를 분석해 줘. 어느 위치(오프트)에 어떤 데이터(PNG, ZIP 등)가 숨어있는지 리스트로 보여준다.
•	실행: binwalk 파일명
2. 자동 추출
가장 많이 쓰는 옵션으로, 스캔 도중 발견된 숨겨진 파일들을 알아서 잘라내어 추출해 줘. 명령어를 실행한 위치에 뺀 밑줄과 파일명 뒤에 extracted가 붙은 폴더가 생기고 그 안에 파일들이 저장돼.
•	실행: binwalk -e 파일명
3. 끝까지 파고들며 추출 (재귀 추출)
압축 파일이나 이미지 안에 또 다른 압축 파일이 겹겹이 숨겨져 있는 매트료시카 같은 상황일 때 써. 더 이상 추출할 파일이 나오지 않을 때까지 끝까지 파고들며 분리해 준다.
•	실행: binwalk -M -e 파일명
4. 엔트로피 분석
파일의 데이터 밀도나 무작위성을 측정해서 그래프나 수치로 보여줘. 파일의 특정 구간이 암호화되었거나 압축되었는지 파악할 때 유용해. 엔트로피가 1에 가까우면 암호화/압축된 구간이고, 갑자기 떨어지면 평문 코드가 존재할 가능성이 커.
•	실행: binwalk -E 파일명
5. 특정 포맷만 지정해서 스캔
특정 파일 형식만 골라서 찾거나 제외하고 싶을 때 사용해. 시간 단축할 때 좋다.
•	PNG만 골라서 스캔할 때: binwalk -y png 파일명
•	ZIP은 제외하고 스캔할 때: binwalk -x zip 파일명
💡 실전 분석 팁
자동 추출(-e)을 돌렸는데 파일이 제대로 안 뽑힐 때가 있어. 빈walk가 파일의 시작 부분은 찾았지만 끝부분을 매직 바이트로 구별하지 못해서 발생하는 문제야. 이럴 때는 빈walk가 알려준 시작 위치(Hex 오프셋)를 확인한 뒤, 리눅스의 dd 명령어를 사용해서 수동으로 그 위치부터 데이터를 잘라내야 해.
