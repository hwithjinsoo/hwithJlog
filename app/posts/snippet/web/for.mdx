```http
FTP {
    HTTP랑 차이점
    HTTP는 Export Objects로 깔끔하게 추출되는데 FTP는 가끔 Follow TCP Stream으로 raw 데이터 직접 뽑아야 하는 경우 있어.

    ftp 필터
    → 명령 채널에서 로그인 정보, 어떤 파일 주고받았는지 확인

    ftp-data 필터
    → 실제 파일 내용 확인
    → Follow TCP Stream 하면 파일 내용 그대로 보여
}

DNS Tunneling {
    dns 필터 걸고
    → 쿼리 도메인 길이 확인
    → 비정상적으로 긴 서브도메인 있으면 의심
    → 같은 도메인으로 쿼리가 엄청 많으면 의심

    dns.qry.name 필드에서 서브도메인 부분만 뽑기
    → base64 디코딩
    → 데이터 복원
}

icmp Tunneling {
    icmp && data
}

c2 통신 분석 {
    Statistics > Conversations
    → 외부 IP랑 통신 많은 거 식별
    → 비정상 포트 확인 (4444, 1337, 8888 같은 거)
    → 해당 IP 필터링해서 Follow Stream

    # 비정상 포트 필터링
    tcp.port == 4444
    tcp.port == 1337

    # 특정 외부 IP 필터링
    ip.addr == 공격자IP

    # 주기적 비콘 탐지 (같은 IP 통신만)
    ip.dst == 공격자IP

    # HTTP로 위장한 C2 (User-Agent 확인)
    http.user_agent

    리버스 쉘 {
        Follow TCP Stream 하면 이런 게 보여:
        whoami
        root
        ls -al
        flag.txt  secret.zip  ...
        cat flag.txt
        flag{reverse_shell_found}
    }

    비콘 신호 {
        0.000s  192.168.1.100 → attacker.com
        60.000s 192.168.1.100 → attacker.com
        120.000s 192.168.1.100 → attacker.com
    }

    http 위장 {
        GET /update HTTP/1.1
        User-Agent: Mozilla/5.0 aGVsbG8gd29ybGQ= << user-Ageng에 base64 데이터 숨기기.
    }

    http 필터 {
        http.request.uri contains ""
    }

}

파일 복원 {
    File > Export Objects > HTTP
    File > Export Objects > FTP-DATA
    File > Export Objects > SMB
        목록에서 파일 선택 후 save

    수상한 패킷 우클릭
    → Follow TCP Stream
    → Show data as: Raw
    → Save As로 저장
    → file 명령어로 실제 포맷 확인
    → 확장자 맞게 바꾸기

    HTTP로 전송된 이미지/zip 복원 → 안에 flag
    FTP로 전송된 파일 복원
    복원한 파일이 이미지면 → 이미지 포렌식으로 연결
    복원한 파일이 zip이면 → 비밀번호 찾기로 연결
}

접근 순서 정리 {
    1. Statistics > Protocol Hierarchy
    어떤 프로토콜이 주로 쓰였는지 파악. 분석 방향 결정.

    2. Statistics > Conversations
    어떤 IP끼리 통신했는지 파악. 수상한 IP 식별.

    3. 프로토콜 필터링
    파악한 프로토콜 기준으로 필터 걸기.
    http, ftp, dns, icmp 순으로 확인.

    4. Follow Stream
    수상한 패킷 우클릭 → Follow TCP/UDP/HTTP Stream.
    주고받은 데이터 전체 확인.
    인코딩된 데이터 보이면 CyberChef로 디코딩.

    5. Export Objects
    File > Export Objects > HTTP/FTP-DATA
    파일 전송 흔적 있으면 여기서 추출.
    추출한 파일이 이미지면 이미지 포렌식으로 연결.

    이미지 포렌식이랑 다르게 pcap은 프로토콜 파악이 먼저야. 거기서 방향이 결정되거든.
}
```
